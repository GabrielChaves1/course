Este é um projeto de código aberto para uma plataforma de cursos online, criado para tornar o aprendizado acessível a todos.

# Como contribuir

Usamos o GitFlow para organização:

- main: Versão estável em prod
- develop: Onde integramos as novidades
- feature: Para novas funcionalidades
- hotfix: Para correções urgentes

# Para contribuir

Faça um fork
Crie sua branch a partir de develop/main
Implemente suas mudanças
Envie um pull request

Todos são bem-vindos para colaborar, independente do nível de experiência.
